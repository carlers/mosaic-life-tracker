## Structural finding and diagnostic
- `useTasks` subscribes owner-local RxDB via `useRxCollection`, yielding a task array. `useTasksByDate` recreates every per-day task array on any new array identity. `CalendarBody` sends the new Map through 3 real `MonthView` grids. Memoized `DayCell` then often rerenders unchanged dates. In a synthetic 1000-task/month one-task edit, fresh per-day arrays produced ~389ms React render versus ~54ms for strict-reference-preserved unchanged days. Same-day dense 1000 did not benefit, and cloned-all snapshots removed the win. This is a provisional non-production upper bound, NOT proof of real RxDB correctness.
