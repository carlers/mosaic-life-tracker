# Isolated E2EE — encrypted legacy outbox recovery capsule (source-only)

New offline-only `legacyPendingRecovery.ts` implements an authenticated client-root-derived AES-256-GCM capsule for the three historically relevant local queue domains (social, message-action, friendship). It requires exact owner/project and 32-byte root, bounds data to 500 unique intents / 1 MiB, uses fresh 128-bit HKDF salt and 96-bit AES-GCM nonce per export, AEAD binds exact project/owner/version, and rejects wrong user/root/tamper/unknown schema before returning any plaintext. The user-readable capsule contains only version, algorithm, salt, nonce and ciphertext. No Appwrite, Storage, queue mutation or network calls. Source unit tests include wrong-account, tamper and fresh randomness.

**NOT a complete backup feature or installed old PWA recovery:** The caller must still obtain a fully fresh, complete owner-scoped queue snapshot while offline from each historical installed version; this module cannot retroactively patch old PWA binaries. It currently exports/decodes a string but has no Settings download/import UX or verified encrypted local snapshot for every unsent RxDB revision/image. It must not be used to clear old storage, connect an old PWA to a sealed backend or enable any account encryption floor. Explicit reviewed recovery/application import and user acceptance remain blocked. Related #2084/#2085.
