# E2EE B — local owner change-page AEAD codec (source-only)

`localOwnerPageCodec.ts` provides a Scratch-project-locked client-side codec for an eventual encrypted local mirror of authenticated owner change pages. Its caller must first pass the server-authenticated `listAndDecryptOwnerChanges` and session gate. It re-derives every opaque server row ID from the unlocked root and original owner/domain ID, refuses unknown fields/owner mismatches, then re-encrypts the *entire* owner-local document including the semantic ID and day fields under a new random local revision with separate `local-cache` HKDF domain. Versioned AEAD additional data binds exact project/owner, opaque row, source domain and revision, server timestamp, key ID and local revision. Serialized output exposes only these necessary routing identifiers and ciphertext; tests prove no task title, original ID, memo or date remains in plaintext.

This **does not write IndexedDB** or implement local CAS/idempotent page application, session/root unlock UI, normal RxDB sync, private media, encrypted disaster recovery, complete old-PWA migration or Production release. A future persistent page applier must atomically write a whole page, reject stale revisions and commit server cursor only after durable ciphertext readback. Source-only; real account data must never be used. Track #1662/#2084.
