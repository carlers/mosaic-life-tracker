# Six-domain historical Scratch owner-v1 ciphertext readback — source only

Tracking: #1662 / #2084. Does not enable legacy ciphertext writes or migrate accounts.

The current dev v2 `fieldManifest.ts` deliberately encrypts task/Diary dates, reminders and visibility. Its ordinary owner record codec must **not** be used to parse the older isolated Scratch `e2ee_owner_v1` rows, whose authenticated routing intentionally disclosed those fields. This standalone **read-only** decoder records the exact six-domain historical server routing allowlist and validates the exact Scratch project, owner, opaque ID, domain, key, deleted flag, private visibility (where relevant), no published data and v1 format. It reconstructs the original AEAD AAD from the v1 routing map, decrypts locally with the supplied root, checks original semantic ID and rejects routing/secret overlap. It accepts both v1 client record shape and the original server get-row wrapper with `deleted` and `updatedAt`. It rejects v2 policy headers, tampering, mixed accounts and unsupported social/Activity domains.

The file contains no network, Appwrite SDK, write, migration or backup restore call. It is only a compatibility building block so future synthetic account migration can separately **read v1, seal v2, independently verify and compare exact decrypted documents before any user-floor change**. Actual v1 rows have historical plaintext metadata and cannot be retroactively made private; they must be explicitly inventoried, replaced/revoked through reviewed signed backend steps, and protected under the old-client fence. No normal Preview/dev/main/Production writes or active sync activation.
