# Task commands — integrated mobile Preview (#1441)

## Scope and release boundary

v0.108.0 integrates the previously reviewed v0.56.0 typed/voice command modules onto the v0.107.3 `dev` application. The Home microphone button is an independent launcher next to Search. Opening it **does not record, download a model, interpret or save anything**. Close or cancel to leave all task data unchanged. The Search control and current Home gesture shortcuts remain independent.

- Type a command such as `Add physics homework to School tomorrow`, `Add buy rice to Errands in backlog`, or a partially complete phrase. Review and edit title, category and date/Backlogs; saving requires a separate explicit Create action. Unknown category creation stays private and owner-only.
- Optional browser speech runs only after informed opt-in and pressing Record. Browser speech services may process microphone audio externally. If unsupported/denied, typed entry remains available; do not claim this mode is offline or private.
- Optional local Whisper Tiny uses an explicit model download and microphone consent, local inference in a worker, a model-cache deletion action, and language choice (English or multilingual); download and decoding require real device tests. No model weights are bundled in Home's initial JavaScript. An optional WebGPU command-suggestion model is a separate opt-in; its output is editable text, never an executable instruction.
- Reviewed bulk commands operate only on currently loaded owner tasks. Match/skip counts and exact task list are shown before execution; bulk writes additionally require a recent successful online sync, selection bounds, typed confirmation, and owner/stale-row checks; undo uses guarded compensating writes, not an atomic database rollback. Do not test on valuable personal data until separately validated on a disposable Scratch account.
- The separate read-only MCP sidecar (`mosaic-mcp-scratch-preview`) remains isolated and unchanged; this UI candidate does **not** deploy or enable MCP writes, Production credentials or backend Functions.

## Manual owner acceptance (Android Brave first)

1. Open Home and tap the microphone button. Confirm no automatic recording/download. Type a single-task command, check title and date, create, and locate it on Calendar; verify incomplete phrases require review.
2. Deny microphone permission and confirm typed fallback. If available, test browser speech with disclosure and stop; then opt into local Whisper on fast connectivity, test cancel and downloaded-model deletion. Verify the app's PWA remains usable offline afterward.
3. Review a bulk command using a disposable Scratch account. Check zero database writes before explicit confirmation; test an invalid/stale selection, Sync Now requirement, cancellation, bounded progress and guarded undo. Never perform mass deletion on actual personal tasks in testing.
4. Check Back gesture/keyboard, Home horizontal/vertical swipes, TOTP login, wallpapers, Light/Dark/Black, task search, user switching during review, offline queued single-task creation/reconnect and PWA update.

## Verification policy

Task commit requires focused CI, then stable Preview exact-SHA canonical acceptance (build and strict initial/Home budgets, DOM and browser shards), official Oracle Scratch Vercel READY and registered alias readback. Real phone voice performance and cloud processing are not proven by CI. Appwrite schemas, Function deployments, Scratch MCP sidecar, dev/main and Production remain untouched by this Preview. A separate future owner approval is required for promotion.

### Optional model-runtime offline behavior

An ONNX WASM runtime is emitted as an optional, large hashed static asset. It is **not** part of the mandatory PWA precache (and must not delay updates or exceed install quotas); the service worker caches only matching same-origin `/assets/ort-wasm-*.wasm` paths on a user-triggered inference fetch. It can then be reused on that device offline. Hugging Face model weights use their separate opt-in CacheStorage namespaces. Deleting Whisper weights does not delete this shared ONNX runtime, which may also be needed by the optional on-device command-suggestion model; clearing browser site storage removes both. Download and offline capability still require real-device verification, including browser storage quota errors.

### Trusted Preview artifact guard for optional WASM

The local ONNX runtime binary is emitted as a hashed static file (approximately 26.9 MB). Existing strict trust verification requires a path-specific bound because the generic tar file-size ceiling is 8 MiB. This Preview restores the previously reviewed v0.56.0 trust rule: **only** `assets/ort-wasm-simd-threaded.asyncify-<8-character hash>.wasm` may be up to **28 MiB**. Every other file remains limited to 8 MiB; total tar expansion remains capped at 32 MiB. SHA-256 archive, inventory and source verification, path/symlink rejection, and canonical CI are unchanged. The regression exercises the accepted runtime plus rejection of unrelated WASM and oversized matching files. This is not production release approval. The WASM is excluded from the required offline shell precache but may be fetched and cached on first opt-in. No external speech audio transmission is introduced.

## v0.111.0 UI and scoped bulk-command refinement

This refreshed Preview is based on current **dev v0.109.0** and retains Diary's new backdrop-save behavior. Home opens a short command input, **Review**, optional collapsed **Voice** and **Local AI** controls. A circular information symbol exposes examples and privacy/safety explanations on desktop hover or tap/keyboard rather than displaying paragraphs at first open. Voice offers browser recognition with explicit third-party processing consent; local Whisper download/recording remains a nested opt-in, and Local AI remains WebGPU opt-in. Model loading progress reports **actual loaded/total bytes** from Transformers.js `progress`/`progress_total` callbacks, labeled per-file versus whole-model; estimated predownload sizes are not guaranteed network totals. HF ONNX q8 Whisper uses ~41–70 MB in weight variants plus ~27 MB shared WASM; Qwen3-0.6B q4f16 is ~570 MB weights plus additional files. No auto-downloading or recording.

New strictly parsed examples: `move all my School tasks to tomorrow`; `move all my tasks from last week to next Monday` (last week means prior Monday–Sunday in device local timezone); `delete all my Family tasks today`; `copy all my tasks today to my clipboard`. Selected tasks are read-only previews until an explicit action. Date moves and deletions preserve bounded 20-row per confirmation, exact typed count, recent sync, owner+category+task-version guards, cancellation and guarded undo; deletion also needs an extra consent checkbox. Clipboard action is separate read-only, max 100 rows, no database mutation and exposes OS clipboard privacy in an information tooltip. No silent source/destination guessing or accidental category creation from unsupported bulk text. Validate full/missing/ambiguous category/date, daylight/date rollover, no matches, mixed owners, stale revisions, >20 changes, >100 clipboard rows, cache/device permissions, extra-contrast, and Light/Dark/Black on Android Brave. Do not run destructive bulk commands on real personal tasks in Preview.
